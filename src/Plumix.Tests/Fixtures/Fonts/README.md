# Native paragraph test fonts

Copied unchanged from the pinned Flutter engine `txt/third_party/fonts` (Flutter 3.47.0,
`4cf24164269`). Ahem provides deterministic native metrics (0.8 em ascent, 0.2 em descent);
Roboto Slab exercises real variable weight shaping and outlines. These assets are embedded only
in the test assembly, never in a published Plumix package.

The adjacent `*.LICENSE.txt` files contain the fonts' embedded copyright/license notices.
Ahem is public domain/CC0. Roboto Slab is Apache 2.0; the full license is `Apache-2.0.txt`.
